# Esly Nails

Web de GitHub Pages con reservas online y panel privado.

## Configuración
1. Crea un proyecto en Supabase.
2. Ejecuta `database/schema.sql` completo en SQL Editor.
3. Crea el usuario de la dueña en Authentication > Users.
4. Edita `js/config.js` con URL, Publishable/Anon Key, WhatsApp, dirección y moneda.
5. Sustituye las imágenes de `images/` por fotos reales.
6. Sube el proyecto a GitHub y activa GitHub Pages.
7. Web pública: `/` | Panel: `/admin.html`.

Nunca pongas una service_role/secret key en el frontend.
